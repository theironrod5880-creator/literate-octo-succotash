Deployment Steps

  1. Commit the repository tree as-is. index.html already sits at repo root.
  2. Confirm .github/workflows/pages-unzip.yml exists (it does — shipped with this build).
  3. Repository Settings > Pages > Source: GitHub Actions.
  4. Push to main. The workflow deploys the root directly.
Tier 1: site.zip is optional. The workflow unzips it only if present, then deploys the root regardless. The old "upload site.zip" step is no longer a prerequisite.
