# 5,880 Concepts Portal

Wheel Within Wheels architecture. The AI host sits at the hub; six spokes open the doors.

## Deploy
1. Push this folder to a GitHub repository root.
2. Settings > Pages > Source: **GitHub Actions**.
3. Push to `main`. `.github/workflows/pages-unzip.yml` deploys the root.

`site.zip` is optional — the workflow unzips it only if present.

## Local preview
    python3 -m http.server 8000
Open http://localhost:8000 — serve over HTTP so the media and export checks report accurately.
